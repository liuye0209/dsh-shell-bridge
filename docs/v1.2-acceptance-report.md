# DSH Shell Bridge V1.2 验收报告

日期：2026-11-05（Asia/Shanghai）

## A. 更新内容

- `ProfileMetadataAdapter` 归一化 PowerShell 版本、平台、能力和来源；缺失 metadata 使用保守 profile。
- Rule Registry 支持注册、注销、查询、优先级、重复 ID 检测和单规则异常隔离；内置规则已接入。
- 纯 JavaScript PowerShell 结构扫描补充嵌套容器、Here-String、转义引号和不完整表达式识别。
- Benchmark 和 DSH CLI 环境检查提供机器可读报告。
- CI 增加手动触发、PowerShell 版本检查和 benchmark/环境 smoke。

## B. 架构变化

`apply()` 读取 metadata → 创建规则注册表 → `tools/pre-execute` 提取命令 → 扫描语法和运行规则 → 返回 DSH 原生 `allow`/`ask`/`deny`。Tokenizer 和 DSH CLI 检查位于独立脚本，不改变 shell 执行器。
